# Architect Portfolio – Tailwind CSS

This is a three page portfolio site for a fictional architecture student, built from a set of wireframes using Tailwind CSS. The aim of the project was a 'pixel perfect' recreation matching the spacing, typography and layout of the designs as closely as possible.

**Live site:** [https://caljosmil.github.io/architect-portfolio-tailwind/](https://caljosmil.github.io/architect-portfolio-tailwind/)

<img width="1301" height="1371" alt="Portfolio Image" src="https://github.com/user-attachments/assets/d094b6bf-559f-46b9-baa9-b8af19202a5f" />

## Pages

- `index.html` - Home: hero, statistics strip, featured project grid, current projects list and newsletter sign-up
- `projects.html` - Selected works: a grid of six project cards with hover effects
- `contact.html` - Contact form, location map and social links

## How to view it

- **Online:** just open the live site link above.
- **Locally:** you can download or clone this repo and open `index.html` in a browser. Tailwind is loaded from a CDN, so you need an internet connection, but nothing needs installing.

## Built with

- HTML
- [Tailwind CSS v4](https://tailwindcss.com/) via the Play CDN
- [Inter](https://fonts.google.com/specimen/Inter) from Google Fonts
- Icons from [Lucide](https://lucide.dev/)
